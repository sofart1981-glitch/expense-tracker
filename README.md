# Трекер расходов

Next.js 15 + React 19 + Tailwind CSS. Данные хранятся в localStorage браузера.

```bash
npm install
npm run dev
```

Затем откройте http://localhost:3000

## Деплой

Сайт: https://sofart1981-glitch.github.io/expense-tracker/

Каждый push в ветку `main` автоматически собирает и публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
